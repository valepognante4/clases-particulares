# 📚 Clases Particulares - Plataforma Web

¡Bienvenido al repositorio de mi sitio web informativo para servicios de clases particulares y preparación académica! Este proyecto fue desarrollado con el objetivo de ofrecer un espacio profesional y directo donde los estudiantes y sus familias puedan conocer los servicios de apoyo escolar, consultar metodologías y contactarme fácilmente.

---

## 🚀 Tecnologías y Estructura
El proyecto está desarrollado con tecnologías web nativas y ligeras para garantizar velocidad y compatibilidad:
* **Estructura:** HTML5 semántico.
* **Estilos:** CSS3 personalizado (`css/`).
* **Interactividad:** JavaScript nativo (`js/`).
* **Multimedia:** Recursos e imágenes organizados en (`images/`).

---

## ✨ Características Principales
* 📖 **Presentación de servicios:** Información detallada sobre el apoyo escolar y las materias que imparto.
* 📱 **Diseño responsivo:** Adaptado para una visualización cómoda tanto en computadoras como en teléfonos celulares.
* 📬 **Sección de contacto:** Canales directos de comunicación para coordinar clases y consultas.
